## 1. Overview

The raid is Scrapfall's core loop: the raider deploys from the Sanctuary with
their loadout to the Dustline, loots containers and Husk wrecks, and must reach
one of four lifts before a 20-minute clock runs out. Extracting keeps
everything carried; dying, timing out or closing the game loses the whole
loadout except the one-slot safe pocket. Risk of loss against reward of loot is
the tension the whole game hangs on.

## 3. Detailed Design

### 3.1 Core rules

1. **Deploy.** At the Checkout the raider picks a drop condition (below), then
   holds E in the Sanctuary lift. The full loadout (2 weapon slots, shield, 16
   bag slots, 1 safe slot) comes topside.
2. **Insertion.** The raider spawns at a random insertion point, facing the
   map centre, at full health. The flashlight starts on only for drops with a
   headlamp.
3. **Raid clock.** `RAID_SECONDS` = 1200 s (20 min). At 0 a living raider dies
   (reason: time).
4. **Containers.** Each raid restocks containers (see `economy.md`), so caches
   move between raids.
5. **Extraction.** Four lifts. At an idle lift's panel, hold E to call it
   (`calling`, 20 s). The call makes noise (radius 90 m) and spawns 3 Husks
   45 m away over the next ~10 s (1 Buzzer, 2 Skitters) heading for the lift.
   After 20 s the doors open (`open`, 25 s). Inside, hold E to extract. After
   25 s the lift returns to `idle` and can be called again.
6. **Results.**
   - Extracted: loadout kept, XP = raid XP + 100, extract count +1.
   - Died / timed out: loadout replaced by an empty one except the safe slot,
     XP = floor(raid XP × 0.5), death count +1.
7. **Closing mid-raid counts as death.** `in_raid` (`profile.inRaid` in the web build) is saved as true at
   deploy; a profile loaded with it still set is treated as a lost raid.
8. **XP and level.** Kills give per-Husk XP (`ENEMIES[*].xp`). Level-ups
   carry XP over.

### 3.2 Drop conditions (`MAPS`)

All three are the same Dustline map with different lighting and multipliers.

| Condition | Husk count × | Loot × | Husk sight × | Headlamp |
|---|---|---|---|---|
| Golden Hour (standard) | 1.0 | 1.0 | 1.0 | no |
| Night Raid | 1.35 | 1.4 | 0.7 | yes |
| Dust Storm | 1.0 | 1.2 | 0.5 | no |

### 3.3 Husk population

- Every spawn point spawns `max(base, round(base × husks) + bonus)` Husks,
  where `bonus` is 1 with probability `husks − 1` when `husks > 1`.
- Network structures are manned (see `husk-network.md`).
- Reinforcements: first after 45 s, then every 50 s, one spawn group at a
  random spawn point more than 70 m from the raider. Wardens and Pouncers
  never respawn.

## 4. Formulas

- `spawnCount = max(base, round(base × husksMul) + (husksMul > 1 && rand < husksMul − 1 ? 1 : 0))`
- `xpOnExtract = raidXp + 100`
- `xpOnDeath = floor(raidXp × 0.5)`
- `xpToNextLevel(level) = 300 + 150 × level`
- Results "gained" = loadout value at extract − loadout value at deploy.

## 5. Edge Cases

- **Dying while the lift is open:** death wins; extraction needs a living raider.
- **Clock hits 0 during the extract fade:** `endRaid` runs once (`mode` guard),
  so whichever happens first decides the result.
- **Tab closed mid-raid:** loadout lost on next load (rule 7). Intended as
  anti-exploit; it also punishes crashes. `INTENT UNKNOWN` whether crash
  recovery is wanted.
- **Calling a lift repeatedly:** only an `idle` lift can be called, so the
  reinforcement wave cannot be stacked on one lift. Calling several lifts can.
- **Empty loadout deploy:** allowed; the free kit exists for broke raiders.

## 8. Acceptance Criteria

- [ ] A raid lasts exactly 1200 s of game time; at 0 a living raider dies.
- [ ] Calling a lift opens it 20 s later and it stays open 25 s.
- [ ] A lift call spawns 3 Husks 45 m from the lift.
- [ ] Extracting keeps every loadout item; dying keeps only the safe slot.
- [ ] Reloading the game with `in_raid` set loses the loadout.
- [ ] Night Raid spawns at least as many Husks as Golden Hour at every spawn point.
- [ ] Level-up threshold is `300 + 150 × level`, with XP carried over.
